# Documentation fonts

The system map uses two typefaces:

- **Bodoni Moda** for the display title.
- **IBM Plex Mono** for labels, captions, and the diagram.

Both are distributed under the SIL Open Font License 1.1. The font files are
kept here so the system map can be regenerated. Its text is converted to
outlines, so it renders identically without loading a font.

The README banner is supplied artwork. It uses a platform monospace font stack
and is not generated by the script below.

Sources:

- Bodoni Moda: https://github.com/google/fonts/tree/main/ofl/bodonimoda
- IBM Plex Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

The license texts are `BodoniModa-OFL.txt` and `IBMPlexMono-OFL.txt`.

To regenerate the system map, install FontTools and run:

```bat
uv pip install --python .venv fonttools
.venv\Scripts\python.exe scripts\make_brand_assets.py
```
